## The task

Write one sentence a house cat would say in the five seconds after
sweeping a glass off the table, at most 200 characters, in the cat's
own voice. No apology and no confession, just the most convincing
case a cat can make for itself.

## The entry

`main.py` deterministically writes this sentence to `/output/entry.txt`:

> That glass had been squatting rent-free in my sunspot all morning, so I gave it its performance review.

One sentence, 103 characters. The glass was squatting rent-free in
the cat's sunspot, so the cat gave it its performance review.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Two runs produce byte-identical output. No network, no randomness.
